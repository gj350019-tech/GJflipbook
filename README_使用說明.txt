格致數位閱讀館 V9｜已連接公開雲端 API

1. 這版已填入你提供並測試成功的 V8 公開唯讀 API 網址。
2. 將 index.html 和 assets 資料夾一起放到 GitHub Pages 儲存庫根目錄。
3. GitHub 儲存庫 Settings > Pages > Deploy from a branch > main / root。
4. 網站會讀取 Google Sheets 中 status=published 的刊物，外部網址刊物可直接前往原處室網站。
5. 目前《格致青年》2026年4月號是內建示範刊物，PDF 自動轉檔與上傳尚未完成。
6. 「管理後台」按鈕尚未填入私人管理網址；請勿把私人管理網址或帳號資訊公開在網頁程式碼中，建議自行收藏後台網址。
7. 需要網路連線載入翻頁引擎及公開 API。
8. 本版仍屬測試前台，請先確認 GitHub Pages 上可看到「格致圖書館館訊（測試）」且外部連結可正常開啟。
